PROBLEMA 01
FINANCEIRO
Comprovantes enviados pelo tutor não podem ser aprovados
------------------------------------------------------------

Problema

Quando o tutor envia um comprovante de pagamento, o administrador visualiza o comprovante, porém a aprovação não funciona.

Objetivo

Corrigir completamente o fluxo de aprovação.

Verificar:

• Frontend
    - botão Aprovar
    - chamada da API
    - payload enviado
    - tratamento de erros
    - atualização automática da tela

• Backend
    - endpoint responsável
    - autenticação
    - autorização
    - validação de permissões
    - atualização do status
    - persistência em banco

• Banco de dados
    - status atualizado corretamente
    - approved_at
    - approved_by
    - histórico

Garantir que:

Tutor envia comprovante

↓

Admin aprova

↓

Status muda imediatamente

↓

Banco atualizado

↓

Tela atualizada

↓

Tutor visualiza pagamento aprovado

Caso exista qualquer exceção, retornar mensagens amigáveis e registrar logs completos.
