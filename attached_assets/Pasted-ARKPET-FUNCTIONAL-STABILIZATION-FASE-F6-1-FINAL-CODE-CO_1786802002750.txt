B — CHAT STICKY BOTTOM

################################################################

============================================================
B1. PROBLEMA

O ResizeObserver atual
verifica near-bottom
DEPOIS do resize.

Isso pode falhar
quando uma imagem grande
aumenta scrollHeight.

============================================================
B2. EXAMPLE

Antes:

distanceToBottom = 0.

Imagem carrega
+500px.

Depois:

distanceToBottom = 500.

Observer testa:

500 < 120
→ false.

Resultado:

viewport pode deixar
de permanecer no bottom.

============================================================
B3. TARGET

Separar:

USER INTENT

de

CURRENT DISTANCE AFTER RESIZE.

============================================================
B4. LOCAL REF

Usar uma ref local equivalente a:

shouldStickToBottomRef

ou nome coerente
com o arquivo.

Não criar hook global.

============================================================
B5. USER SCROLL

No scroll real do container,
atualizar:

shouldStickToBottomRef.current =
distanceToBottom < threshold.

============================================================
B6. INITIAL LOAD

Ao abrir uma conversa:

shouldStickToBottomRef.current = true

e realizar initial scroll
imediato ao bottom.

============================================================
B7. RESIZE

Quando ResizeObserver detectar
mudança de altura:

SE:

shouldStickToBottomRef.current === true

ENTÃO:

scrollTop = scrollHeight.

============================================================
B8. IMPORTANT

Não recalcular a intenção
somente depois do resize.

============================================================
B9. USER HISTORY

Quando usuário subir
para ler histórico:

scroll event

→ shouldStickToBottom = false.

ResizeObserver
não deve puxá-lo de volta.

============================================================
B10. NEW MESSAGE

Antes/ao processar nova mensagem,
preservar comportamento:

se usuário está acompanhando bottom
→ auto-scroll.

se está lendo histórico
→ não sequestrar.

============================================================
B11. PROGRAMMATIC SCROLL

Evitar que scroll programático
crie comportamento oscilante.

Não criar:

setInterval

loop

polling

global scroll manager.

============================================================
B12. CONVERSATION CHANGE

Ao mudar conversation/thread:

resetar:

initialScrolled

e:

shouldStickToBottom = true.

============================================================
B13. MESSAGE ORDER

Preservar:

ASC.

============================================================
B14. QUERIES

NÃO alterar:

React Query

message API

pagination

polling

send mutation

attachments.

============================================================
B15. STATIC TEST MATRIX

Validar por código:

initial conversation
→ stick true.

user scrolls up
→ stick false.

large media resize while stick=true
→ bottom restored.

large media resize while stick=false
→ no movement.

conversation changes
→ stick true novamente.
