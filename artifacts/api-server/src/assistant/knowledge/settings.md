# Configurações da Creche no ArkPet

## Visão Geral
A tela de configurações (`/settings`) permite ao administrador personalizar as regras operacionais e dados cadastrais da creche.

## Dados Principais
- **Informações Gerais:** Nome fantasia, razão social, CNPJ, telefone de contato e endereço físico.
- **Horários de Operação:** Horários padrão para recebimento e entrega de pets (Check-in e Check-out).
- **Capacidade Operacional:** Limite máximo de pets que a creche comporta simultaneamente para Day Use e Hospedagem.
- **Regras de Cancelamento:** Política de prazos e eventuais taxas para cancelamentos de reservas com aviso prévio.

## Acesso
- Apenas administradores (`creche_admin` e `master_admin`) possuem permissão para alterar as configurações estruturais da creche.
